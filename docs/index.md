# Unitree G1

This manual describes the Living Proof Labs Unitree G1 robot package: pinned
models, published controllers and simulated hallway evidence. Start with the
[guide](guide.md) for installation, configuration and commands.

The package runs in MuJoCo. Simulation evidence is not a hardware safety claim.
Living Proof Labs does not train the controllers. Assessment and grading belong
to the pinned verifier and reporter, not this robot package.

verifier and reporter manuals. Their source releases are pinned in this package's
`verification.lock.json`; a current manual does not change those dependencies.
