# Unitree G1

This manual describes the Living Proof Labs Unitree G1 robot package: the
pinned model, the published controllers and the MuJoCo adapter. Start with the
[guide](guide.md) for installation, configuration and commands.

The package runs in MuJoCo. Living Proof Labs does not train the controllers.
This package does not select a world or a scenario, and it does not grade.
